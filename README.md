# Карта английского

Локальный тест уровня английского: биография, самооценка, чтение и слушание (EF SET), грамматика, письмо и речь с записью. Результат — профиль по каждому навыку, карта ошибок и беглость в цифрах, а не одна буква. Всё остаётся на этом компьютере.

Спека: [Карта английского — спека](https://claude.ai/artifact/7rhPCfkpWd52afNYe6Zotn).

## Как пройти

Есть две одинаковые по содержанию версии.

**Онлайн:** https://letulip.github.io/karta-english/ в Chrome. Сервера там нет: прогресс хранится в этом браузере (IndexedDB) и никуда не отправляется. После каждого захода и в конце скачай архив — кнопка «Скачать архив» на главном экране. Тем же архивом можно восстановить прогресс на другом устройстве.

**Локально:**

```bash
npm run exam
```

Открой http://localhost:5180 в Chrome. Каждый ответ сразу пишется в `results/<сессия>/`.

Шесть частей в три захода, около 3,5 часа:

| Заход | Части | Время |
| --- | --- | --- |
| 1 | биография, самооценка, EF SET | около 80 минут |
| 2 | грамматика и лексика, письмо | около 100 минут |
| 3 | речь | около 35 минут |

Вкладку можно закрыть посреди части: прогресс восстановится. Таймер письма при этом не останавливается.

## После теста

Скажи Claude «тест пройден, сделай разбор», а для онлайн-версии — ещё и путь к архиву. Он сделает следующее:

0. `npm run import -- ~/Downloads/karta-english-<сессия>.zip` — только для онлайн-версии: распакует архив в `results/` и сделает сессию активной.
1. `npm run transcribe` — расшифрует речь локально через Whisper и посчитает метрики беглости ([pipeline/README.md](pipeline/README.md)).
2. `npm run dossier` — сведёт всё в `dossier.md`, а для слепой второй оценки — в `rater-input.md`.
3. Сделает разбор по [analysis/prompt.md](analysis/prompt.md) и шкале [analysis/rubric.md](analysis/rubric.md) и запишет его в `report.md`.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run exam` | тест на http://localhost:5180, результаты в `results/` |
| `npm run demo` | то же на :5181, результаты в `.demo-results/` — для проверок, не для теста |
| `npm run build:pages` | сборка онлайн-версии в `dist/`: хранилище в браузере, база `/karta-english/` |
| `npm run import -- <архив>` | распаковать архив онлайн-версии в `results/` |
| `npm run transcribe` | расшифровка и метрики речи для активной сессии |
| `npm run dossier` | досье сессии для разбора |
| `npm run audio` | заново озвучить вопросы части 6 голосами macOS |
| `npm test` | модульные тесты: подсчёт баллов, контент, API сохранения, банк грамматики |
| `npm run e2e` | сквозной прогон всех шести частей в Chrome с поддельным микрофоном — в обеих версиях, с архивом и восстановлением |
| `npm run check` | типы, модульные тесты и e2e |

## Устройство

- `src/content/` — вопросы и задания: биография, утверждения самооценки, 60 заданий грамматики, письмо, речь.
- `src/components/` — экраны частей, `src/lib/` — сохранение, журнал условий, таймеры, запись, подсчёт.
- `src/lib/backend/` — два хранилища за одним интерфейсом: `server.ts` для локальной версии, `browser.ts` (IndexedDB) для онлайн-версии. `src/lib/archive.ts` — архив сессии в формате папки `results/<сессия>/`.
- `server/resultsApi.ts` — локальный API внутри сервера Vite: пишет файлы только в папку активной сессии и принимает запросы только со своего хоста.
- `.github/workflows/deploy.yml` — при пуше в main: типы, модульные тесты, оба сквозных прогона, сборка и публикация на Pages.
- `public/audio/` — озвученные вопросы (`npm run audio`).
- `pipeline/` — расшифровка Whisper, детектор пауз Silero VAD, метрики.
- `analysis/` — промпт разбора, шкала, слепая оценка, шаблон отчёта.

`results/`, `.demo-results/` и `.e2e-results/` в git не попадают: там личные ответы и записи голоса.
