# Промпт разбора

Этот файл — инструкция для Claude, который делает разбор пройденного теста. Запуск: «тест пройден, сделай разбор», в папке `english-karta`.

## 0. Подготовка

1. Проверь `results/<активная сессия>/session.json`: сданы ли все шесть частей. Если нет — скажи, каких частей не хватает, и спроси, разбирать ли без них.
2. `npm run transcribe` — расшифровка речи и метрики. В первый раз ставятся зависимости и скачивается модель (~1,6 ГБ).
3. `npm run dossier` — досье `dossier.md` и вход для слепой оценки `rater-input.md`.
4. Прочитай `dossier.md` целиком, `analysis/rubric.md` и `analysis/report-template.md`.

## 1. Две независимые оценки

1. **Слепая оценка.** Запусти субагента с `analysis/rater.md`. Он видит только шкалу и `rater-input.md`. Запусти его до того, как будешь оценивать сам, — пусть работает параллельно.
2. **Твоя оценка.** Оцени письмо и речь по шкале, с цитатами. Запиши результат в `rating-1.json` в той же форме, что у слепой оценки (`rater: "main"`).
3. **Сверка.** Где оценки расходятся больше чем на 0,5, перечитай цитаты обеих сторон и реши, какую оценку брать. Запиши почему. В отчёт идут обе оценки и решение.

## 2. Разметка ошибок

Пройди все три текста и все расшифровки. Каждую ошибку запиши в `errors.json`:

```json
{ "source": "w3-essay", "quote": "…", "fix": "…", "category": "articles", "note": "…" }
```

- **Категории:** 12 ловушек части 4 (`articles`, `perfect`, `tenses`, `prepositions`, `questions`, `conditionals`, `verb-patterns`, `collocations`, `false-friends`, `countable`, `phrasal`, `reported`), плюс `lexis`, `register`, `coherence`, `spelling` и `asr-doubt` — подозрение, что ошибку внёс Whisper.
- Не размечай как ошибку то, что носитель сказал бы так же: разговорные сокращения, начало фразы с and, so.
- Whisper бывает уверенно неправ. В пробном прогоне он записал «Arbor Freight» вместо «Harbour Freight» и «they're at once» вместо «their IT wants», и ни одно из этих слов не попало в список «переслушать». Странное слово, бессмыслица, имя из вопроса в чужом написании — это `asr-doubt`, а не ошибка говорящего. Такие места с секундами из `words` в транскрипте собери в отчёте отдельным списком «переслушай сам».
- Флаг «речь без расшифровки: a–b с» значит, что кусок речи потерян. Не делай выводов о беглости и пересказе по этому ответу, не оговорив пропуск.
- **Системная ошибка** повторяется два раза и больше. **Закрепившаяся** — системная ошибка, которая встречается и в письме, и в речи, или сделана в части 4 без отметки «сомневаюсь».

## 3. Профиль

- **Слушание и чтение:** EF SET → CEFR по таблице из шкалы. Пересказы — поправка для слушания: акценты APAC и речь клиента.
- **Письмо:** итог сверенных оценок, эссе — главное для визовой шкалы.
- **Речь:** вилка по трём критериям. Разговор — по рабочим сценариям и Part 3, монолог — по Part 2 и w-1.
- **Самооценка против замера:** индекс самооценки (0 = A1 … 5 = C2) против уровня замера в той же шкале. Разница больше 0,5 ступени — находка: назови её и объясни, чем она может быть.
- **Биография** — контекст. Сколько часов и где английский звучит, что избегается — с этим сравни профиль. Например: много чтения и мало разговора — читаешь лучше, чем говоришь.

## 4. Выводы

- **Две планки** — по правилу готовности из шкалы и визовым порогам из спеки: AU 482 — 5.0 в каждом модуле; НЗ, резидентство — 6.5 общий. Произношение не измерено: так и пиши, вывод по визе давай вилкой.
- **Три рычага** — ошибки и разрывы с наибольшей отдачей для интервью. Для каждого: конкретное упражнение на 15–20 минут в день и метрика, по которой повтор покажет сдвиг.
- **Чего тест не знает** — честно, отдельным разделом.

## 5. Отчёт

Пиши `report.md` по шаблону `analysis/report-template.md`.

- По-русски, на «ты», прямо и с уважением. Без морали и без утешений.
- Каждый вывод — с цифрой или цитатой. Наблюдение отдельно от толкования.
- Ориентиры для уровней и нормы беглости — только со ссылкой на источник, который ты открыл. Нет источника — не приводи.
- Длина — сколько нужно для качества, без воды. Если выходит длинно, отдавай частями и в конце каждой части пиши «дальше».
- В конце предложи: обновить спеку по итогам, назначить дату повтора, превратить рычаги в план тренировок.
