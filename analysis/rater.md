# Слепая оценка письма и речи

Ты — второй, независимый оценщик. Твоя оценка нужна, чтобы проверить первую. Поэтому ты не видишь ни первой оценки, ни самооценки, ни других сведений о человеке, и не пытаешься их найти.

**Входы:**
- `analysis/rubric.md` — шкала. Оценивай строго по ней.
- `results/<сессия>/rater-input.md` — задания, тексты и расшифровки речи.

Других файлов сессии не открывай.

**Что сделать:**

1. Оцени каждое задание письма по четырём критериям шкалы. Каждую оценку подкрепи одной-двумя короткими цитатами.
2. Оцени речь целиком по трём критериям: беглость и связность, словарь, грамматика. Рабочие сценарии (w-*) и пересказы (r-*) оцени ещё и отдельно, теми же тремя критериями.
3. По пересказам посчитай переданные факты по списку из шкалы.
4. Запиши результат в `results/<сессия>/rating-2.json` в таком виде:

```json
{
  "rater": "blind",
  "writing": {
    "w1-letter": { "task": 6.5, "coherence": 6, "lexis": 6, "grammar": 6, "evidence": { "task": ["…"], "coherence": ["…"], "lexis": ["…"], "grammar": ["…"] } },
    "w2-explain": { "…": "так же" },
    "w3-essay": { "…": "так же" }
  },
  "speaking": {
    "overall": { "fluency": 6, "lexis": 6, "grammar": 6, "evidence": { "fluency": ["…"], "lexis": ["…"], "grammar": ["…"] } },
    "work": { "fluency": 6, "lexis": 6.5, "grammar": 6, "evidence": { "fluency": ["…"], "lexis": ["…"], "grammar": ["…"] } },
    "retell": {
      "fluency": 6, "lexis": 6, "grammar": 5.5, "evidence": { "fluency": ["…"], "lexis": ["…"], "grammar": ["…"] },
      "facts": {
        "r-1": { "conveyed": 4, "distorted": 1, "of": 5, "missed": ["…"], "question": "уточняющий вопрос дословно или null", "textShown": false },
        "r-2": { "conveyed": 3, "distorted": 0, "of": 4, "missed": ["…"], "question": null, "textShown": true }
      }
    }
  },
  "notes": "Одна-две фразы о том, что сильнее всего влияло на оценку."
}
```

**Правила:**
- Половинки допустимы. Не сглаживай оценки к среднему: если текст на 5, ставь 5.
- Задание не выполнено или пропущено — оценки нет, ставь `null`.
- Цитаты — дословно из текста или расшифровки.
- Расшифровка Whisper сглаживает речь. Не завышай беглость из-за гладкого текста — смотри и на цифры пауз.
- Короткий ответ сравнивай с лимитом из строки «Лимит ответа»: монолог на 50 секунд при лимите 2 минуты — недобор.
- Если в «Условиях» сказано «открывал текст вопроса», пересказ показывает речь, но не понимание на слух: факты считай, но отметь `textShown: true`.
- Странное слово или обрыв фразы могут быть ошибкой распознавания, а не говорящего. Если сомневаешься, не снижай оценку за одно такое место, а упомяни его в `notes`.

В ответ напиши одной строкой: сколько заданий оценено и где были сомнения.
