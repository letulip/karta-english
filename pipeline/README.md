# Расшифровка речи и метрики беглости

Записи части 6 расшифровываются прямо на маке. Whisper даёт слова, а детектор речи Silero VAD — точные границы пауз. Из этого считаются метрики беглости и словаря. В сеть ничего не уходит: модель Whisper (~1,6 ГБ) один раз скачивается в кэш Hugging Face, дальше всё работает офлайн.

## Запуск

```bash
npm run transcribe
```

Скрипт берёт активную сессию из `results/active.json`. Другую сессию можно передать аргументом:

```bash
bash pipeline/run.sh results/a-2026-10-21
```

- В первый раз скрипт создаёт окружение `pipeline/.venv` и ставит зависимости, это около минуты.
- Модель скачивается при первой расшифровке; заранее её можно скачать командой `bash pipeline/run.sh --setup`.
- Готовые расшифровки повторно не делаются; `--force` расшифровывает всё заново.
- Скорость на M4 — примерно ×10 к реальному времени: 20 минут записей расшифровываются за 2–3 минуты.

Результат лежит в папке сессии:

- `transcripts/<вопрос>.json` — текст, слова с таймкодами и уверенностью Whisper, границы речи от детектора, отчёт второго прохода (`recovery`);
- `metrics.json` — метрики по каждой записи, по типам вопросов и в целом; в блоке `definitions` — определения по-русски.

**Второй проход.** Защита Whisper от галлюцинаций на тишине иногда выбрасывает настоящую фразу целиком. Поэтому после основного прохода скрипт ищет речь по детектору (от 0,4 с), на которую не пришлось ни одного слова. Каждый такой кусок с полями по 0,3 с расшифровывается отдельно, уже без этой защиты, и слова встают на своё место; они помечены `rec: true`. Если Whisper заново услышал только соседнее слово (хвост обрезанного слова), кусок считается покрытым. Если не услышал ничего, во `flags` записи появляется «речь без расшифровки: 29,7–32,4 с».

Самопроверка синтезирует ответы голосами macOS с паузами в известных местах, гоняет готовую запись `fixtures/dropped-sentence.webm` (синтез; на ней первый проход теряет фразу) и сверяет результат:

```bash
bash pipeline/selftest.sh
```

## Что меряем

| Метрика | Как считаем |
| --- | --- |
| Латентность | от начала записи до начала речи |
| Темп речи | слова в минуту в окне речи, без «uh/um» |
| Темп артикуляции | слоги в секунду без пауз от 0,25 с |
| Длина фразы между паузами | среднее число слов между паузами от 0,25 с |
| Паузы | сколько в минуту, средняя и самая длинная; отдельно на границе фразы и внутри неё |
| Заполненные паузы | «uh», «um», «er» и похожие в минуту |
| Повторы | то же слово или та же пара слов подряд |
| Разнообразие слов | MATTR, окно 50 слов |
| Редкие слова | доля словоформ вне 2000 самых частых (wordfreq) |
| Переслушать | слова, в которых Whisper не уверен (вероятность ниже 0,5) |

Паузы считаются от 0,25 с — обычный порог в исследованиях беглости на втором языке. У каждой записи есть `pauseList`: после какого слова была пауза и сколько она длилась.

## Ограничения

- **Паузы меряет детектор, а не Whisper.** Таймкоды слов Whisper растягивают слово на соседнюю тишину: в самопроверке 1,5 с тишины Whisper показал как 0,66 с. Детектор находит ту же паузу как 1,44 с. Без детектора скрипт откатывается к таймкодам Whisper и помечает запись флагом.
- **Whisper «причёсывает» речь.** Повтор «the the» в самопроверке он убрал, «эээ» тоже часто выкидывает. Поэтому заполненные паузы и повторы — нижняя оценка.
- **Граница фразы — по пунктуации Whisper.** Многоточие («because...») он ставит на запинке, такая пауза считается внутри фразы. В остальном деление на «на границе» и «внутри фразы» приблизительное.
- **Произношение не оценивается.** Список «переслушать» — лишь подсказка, где оно могло помешать распознаванию.
- **Короткие ответы.** Если в записи меньше 50 слов, разнообразие считается по всей записи и выходит выше, чем у длинных. Сравнивать стоит ответы одного типа.
- **Числа** считаются как 2 слога. Слоги берутся из словаря произношений CMU, незнакомые слова оцениваются по гласным.
